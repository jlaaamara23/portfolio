# Jlaa Amara — Portfolio

Personal portfolio site for **Jlaa Amara** (Computer Science), built from the CV and ready to deploy on Vercel.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

1. Import the GitHub repo `jlaaamara23/portfolio` in [Vercel](https://vercel.com) (account: `jlaa.amarajlaa@gmail.com`).
2. Framework preset: **Next.js** (auto-detected).
3. Deploy — production URL will be assigned by Vercel.

Or with the CLI (requires a token for that account):

```bash
npx vercel --prod --token "$VERCEL_TOKEN"
```
